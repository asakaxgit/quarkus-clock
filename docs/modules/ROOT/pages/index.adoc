= Quarkus Clock

include::./includes/attributes.adoc[]

Provides an injectable `java.time.Clock` for Quarkus applications.
Use the system clock in production, a fixed instant for deterministic tests, or an adjustable clock when you need to move time forward in tests and development.

Supported clock types:

* `system` (default) — `Clock.systemUTC()`
* `fixed` — a constant ISO-8601 instant
* `adjustable` — an `AdjustableClock` you can advance or travel

== Installation

Add the `io.quarkiverse.clock:quarkus-clock` extension to your build file.

For instance, with Maven, add the following dependency to your POM file:

[source,xml,subs=attributes+]
----
<dependency>
    <groupId>io.quarkiverse.clock</groupId>
    <artifactId>quarkus-clock</artifactId>
    <version>{project-version}</version>
</dependency>
----

With Gradle:

[source,groovy,subs=attributes+]
----
implementation("io.quarkiverse.clock:quarkus-clock:{project-version}")
----
